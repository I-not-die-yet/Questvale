# Approved artwork preview

Open http://127.0.0.1:4174/approved.html with the existing local server.
This is a separate static artwork preview, not the movable Canvas prototype.

The user-approved image is copied unchanged to assets/questvale-hackathon-approved.png
from the built-in image generation result exec-625c503f-2b58-477c-b1e3-10c7160958c4.png.
It was created in this chat on 2026-11-13 as a reference-guided edit of the earlier
four-zone concept. No paid API was called and no third-party game art was used.
Image-model output has not been verified to match an exact native pixel grid.
Provider terms and eventual competition AI disclosure still require team review.

approved.html, approved.css and approved.mjs use the actual approved image as
the visible scene. Accessible HTML controls align to its Advisor button,
Hackathon label, doorway and noticeboard; E opens Hackathon and native Escape
closes the dialog. The advisor is a local input preview with no network, analysis
or persistence. Category panels do not contain invented opportunity listings.
The standalone host owns the provisional selection using the existing contract.

The image still contains baked UI and a baked character. Therefore movement,
camera scrolling, asset layering and collision are NOT enabled here. The old
prototype remains at /. This preview deliberately preserves the accepted visual
instead of claiming a flat image is a playable world.

Checks: JavaScript syntax passed; real-browser Hackathon click and dialog,
Advisor input, Escape dismissal and focus return were observed. Desktop
1440x810 and narrow layout were visually inspected. Evidence:
assets/approved-desktop-check.png.
No backend integration, mobile device test or full accessibility certification.
